Curso de Matemáticas

Módulo 1: Operaciones Fundamentales

Descomponer números agiliza el cálculo mental. Para $48 + 37$, puedes sumar $48 + 30 = 78$, y luego $78 + 7 = 85$.

Módulo 2: Domina las Fracciones

Para sumar fracciones con distinto denominador como $\frac{1}{2} + \frac{1}{4}$, convertimos $\frac{1}{2}$ a equivalencia: $\frac{2}{4}$. Así, $\frac{2}{4} + \frac{1}{4} = \frac{3}{4}$.

Módulo 1: Lenguaje Algorítmico y Ecuaciones

Para despejar $3x + 5 = 20$: restamos $5$ de ambos lados ($3x = 15$) y dividimos entre $3$ ($x = 5$).

Módulo 2: Teorema de Pitágoras

En todo triángulo rectángulo: $a^2 + b^2 = c^2$. Con catetos de $3$ y $4$: $c = \sqrt{3^2 + 4^2} = \sqrt{25} = 5$.

Módulo 1: Factorización Avanzada

La diferencia de cuadrados: $a^2 - b^2 = (a - b)(a + b)$. Permite simplificar expresiones racionales complejas.

Módulo 2: Trigonometría Analítica

Valores notables: $\text{sen}(30^\circ) = \frac{1}{2}$, $\text{cos}(60^\circ) = \frac{1}{2}$. Identidad pitagórica: $\text{sen}^2(\theta) + \text{cos}^2(\theta) = 1$.
